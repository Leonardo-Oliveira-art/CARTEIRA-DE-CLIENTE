# CARTEIRA-DE-CLIENTE

Carteira de Clientes  Este projeto marca o começo da minha jornada como desenvolvedor e empreendedor. Nasceu de uma necessidade real: ao abrir meu próprio negócio, eu precisava de um jeito simples e organizado de acompanhar meus clientes, os sistemas que entrego e os valores de cada projeto. Em vez de usar uma ferramenta pronta, decidi construir a minha.  A Carteira de Clientes é um sistema leve, feito apenas com HTML, CSS e JavaScript puro, sem frameworks e sem servidor. Nele eu cadastro cada cliente com seus contatos, a loja ou empresa, onde o sistema está hospedado, o link do projeto e uma descrição sobre o negócio. Também controlo a parte financeira: valor do projeto, mensalidade, vencimento e cada pagamento recebido ou pendente, com um resumo que mostra a receita mensal e o que ainda está em aberto.  A privacidade foi uma escolha desde o início. Os dados ficam salvos apenas no navegador de quem usa, e podem ser exportados e importados em JSON para backup. Assim, mesmo hospedado publicamente, nenhuma informação dos clientes sai do meu computador.  Mais do que uma ferramenta, este projeto é o primeiro passo de uma carreira que estou construindo com dedicação, um cliente de cada vez.  Tecnologias: HTML5, CSS3, JavaScript (Vanilla), LocalStorage, JSON
